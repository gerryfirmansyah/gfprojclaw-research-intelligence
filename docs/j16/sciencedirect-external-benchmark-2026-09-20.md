## Interpretation boundary
These observations establish only that the current 3-Work Project Corpus is not a defensible representation of the whole research field. Counts reported inside external review papers belong to those papers' own protocols/scopes and MUST NOT be copied into GFPROJCLAW as its Research Universe count.

ScienceDirect is an Elsevier platform and is not ground truth for the global literature. Benchmark results remain external observations until a reproducible provider/query/run ingestion design records them canonically. No benchmark item is automatically promoted, screened-in, or used to establish a gap.

## Next implementation implication
GFPROJCLAW needs a canonical external-discovery observation layer that stores source, exact query, run time, pagination/result count where available, record identifiers, retrieval/access state, and deduplication linkage. Only then should the UI compute overlap/source-unique/discovery-to-project funnels.
